# Move sounds

| File           | Played when                                                |
| -------------- | ---------------------------------------------------------- |
| `move.wav`     | A piece moves to an empty square                           |
| `capture.wav`  | A piece is captured (en passant included)                  |
| `castle.wav`   | Castling (two knocks: king, then rook)                     |
| `check.wav`    | A move gives check                                         |
| `promote.wav`  | A pawn promotes                                            |
| `illegal.wav`  | A piece is dropped or tapped onto a square it cannot reach |
| `game-end.wav` | Checkmate, stalemate or another drawn position             |

## Source and licence

Every file is **original work generated by `scripts/generate-sounds.mjs`** (run `pnpm sounds`
to regenerate them, byte for byte). They are synthesized: a short burst of low-passed noise
for the "knock" of a piece on a wooden board, a pitched body that sags as it fades, and
soft bell-like partials for check, promotion and game end.

They are released under **CC0 1.0** (public domain dedication,
<https://creativecommons.org/publicdomain/zero/1.0/>). No recording, sample or asset from
Chess.com, Lichess or any other product was used or analysed: the sounds aim at the same
kind of interaction feedback (a soft wooden tap, a heavier capture, a bright ping on check)
but are not copies of anyone's audio.

Format: mono, 16-bit PCM, 44.1 kHz WAV, 12–95 KB each (about 270 KB in total). They are
part of the PWA precache, so they work offline.
